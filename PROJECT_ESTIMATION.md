Проект разрабатывался в период с **4 апреля по 22 мая** (суммарно **49 календарных дней** или 7 недель). В данном документе приведена оценка трудозатрат по задачам по методологии PERT, а также описаны риски и стратегии их снижения.

## Стратегия управления ключевыми рисками проекта

1. **Технический риск: Нестабильность LLM API (KIE.AI/OpenAI)**  
   * *Симптом:* Таймауты или некорректный формат ответа.  
   * *Решение:* Внедрена библиотека-обертка `llm-client.ts` с поддержкой 3-х повторных попыток запроса и автоматической очисткой JSON регулярными выражениями.
   
2. **Продуктовый риск: Отклонение заявок налоговыми органами**  
   * *Симптом:* ИИ пропускает рутинные задачи как R&D, создавая угрозу для клиента.  
   * *Решение:* В пайплайн встроен агент-критик ("Devil's Advocate"), снижающий баллы при обнаружении стандартных CRUD/UI процедур, а также реализовано мажоритарное голосование на границах решения (0.40–0.65).
